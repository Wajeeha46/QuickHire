# QuickHire

QuickHire is an Android job marketplace application designed to connect customers with skilled workers for everyday services. The app allows users to browse categories, view profiles, request hiring, and manage active hires through Firebase-powered authentication and database features.

## Project Purpose
This project was built to demonstrate practical Android app development, Firebase integration, UI/UX design, and real-world service marketplace flows that are highly relevant for a software developer portfolio and resume.

## Features
- User authentication with Firebase
- Service categories and worker browsing
- Worker profile details and booking flow
- Hire request form
- Active hire tracking and user dashboard
- Contact and About pages
- Material UI design with Android views and navigation

## Tech Stack
- Kotlin
- Android SDK
- Firebase Authentication
- Firebase Firestore
- Firebase Storage
- Glide for image handling
- Material Components
- Gradle

## App Flow
1. User signs up or logs in.
2. User browses workers by category.
3. User views worker details and submits a hire request.
4. User can track active hires in their dashboard.

## Run Locally
```bash
./gradlew assembleDebug
adb install -r app/build/outputs/apk/debug/app-debug.apk
```
